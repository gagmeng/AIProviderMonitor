通知

微信（企业微信群机器人）

  1. 在 PC 端微信中打开任意一个企业微信群（没有可先自行创建一个内部群）；
  2. 点击群右上角 「…」→ 群机器人 → 添加机器人，创建一个机器人并自定义名称（如“状态监控”）；
  3. 创建完成后复制弹出的 Webhook 地址（形如 https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxx）；
  4. 将地址粘贴到上方输入框，打开开关并点击「发送测试消息」验证。

QQ（机器人 HTTP 上报）

  1. 准备一个 QQ 小号作为机器人，部署一个 OneBot v11 标准协议实现，推荐任选其一：
    • NapCat（github.com/NapNeko/NapCatQQ）—— 免费开箱即用，支持 Windows；
    • Lagrange.OneBot（github.com/LagrangeDev/Lagrange.Core）—— 轻量 .NET 实现；
    • go-cqhttp（已停止维护但仍有大量用户）。
  2. 在机器人配置中开启 HTTP 服务端（如 NapCat 的 servers.httpServers，go-cqhttp 的 servers.http），设置监听端口（默认 5700），本程序将调用其 /send_private_msg 与 /send_group_msg 接口；
  3. 若配置文件中设置了 access_token，请同步填写到上方「Access Token」，本程序会以 Authorization: Bearer 头携带；
  4. 机器人登录成功后，在上方填入机器人 HTTP 服务地址（如 http://127.0.0.1:5700）、上报目标（接收消息的 QQ 号或群号）与上报类型，打开开关并点击「发送测试消息」验证。

钉钉（群机器人 Webhook）

  1. 在钉钉中打开一个群聊（没有可先创建一个内部群），点击群右上角 「…」群设置 → 机器人；
  2. 选择 添加机器人 → 自定义（通过 Webhook 接入）；
  3. 安全设置任选其一（推荐加签）：
    • 加签：创建后复制 SEC 开头的密钥，填到上方「加签密钥」；
    • 自定义关键词：填入 监控（本程序消息包含该词，可直接命中）；
    • IP 地址段：填写本机公网 IP。
  4. 完成后复制 Webhook 地址（形如 https://oapi.dingtalk.com/robot/send?access_token=xxxx），粘贴到上方输入框，打开开关并点击「发送测试消息」验证。

备份与还原

创建备份

将当前全部服务商配置与通知设置导出为一个 JSON 备份文件。自动备份每日生成一次，保留最近 10 份；也可随时手动创建。

从备份还原

选择一个备份文件后按所选方式还原。「覆盖」将整体替换当前全部数据；「合并」仅把备份中的服务商并入当前列表（按 URL 去重），通知设置保持不变。
